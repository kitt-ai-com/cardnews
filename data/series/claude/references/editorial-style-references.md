# 카드뉴스 참조 시리즈 — 디자인·레이아웃·콘텐츠 패턴

> 사용자가 2026-05-02에 제공한 7개 레퍼런스 이미지 분석. 이후 모든 카드뉴스 작업에서 분석/카피/디자이너 에이전트가 이 문서를 먼저 읽고 패턴을 따라야 함.

## 참조 시리즈 두 가지

### A) DEEPDIVE 시리즈 (사진/스크린샷 헤로형)
- 출처: `실리콘밸리 VC가 오늘 본 딥다이브` / `ianpark.vc`
- 일레븐랩스, Voicebox 등 AI/SaaS 비평
- **상단 50-60%: 진짜 사진 / 실 스크린샷 / 타이포그래피 아트**
- 하단 40-50%: 타이틀 + 본문
- 추상 글로우 X — 콘텐츠 자체가 비주얼

### B) 짐코딩 MCP 시리즈 (콘텐츠 블록형)
- 출처: `짐코딩 | 클로드 코드 완벽 마스터` / `#MCP쉽게이해하기`
- Claude Code/MCP 교육 콘텐츠
- **배경 이미지 0** — 카드/표/다이어그램이 비주얼
- 큰 여백 (하단 30-40% 비움)
- 색상 = 정보 (장점=녹/한계=빨/대안=파/메인=주황 또는 라임)

→ Claude 시리즈는 **B형 (짐코딩 스타일)** 채택.

## 핵심 패턴 (Claude 시리즈 적용 기준)

### 1. 브랜드 스트립 (모든 페이지 상단 고정)

```
[●] @uhuru_nomadlife  |  클로드 코드 처음 시작            #처음시작
                                                        01 / 08
```

- 좌측: 작은 아바타(라임 원, 영문 1자) + 핸들(흰 굵은) + 구분자(`|`) + 시리즈명(muted)
- 우측: 해시태그(라임)
- 페이지 번호: 스트립 아래줄 우측 (`01 / 08`)

### 2. 라벨 + 타이틀 (고정 y좌표)

```
[소형 라벨 — 라임]              ← y=220
[큰 타이틀 두 줄, 한 단어만 accent]  ← y=280
```

- 라벨 예: `한 줄 정의`, `3가지 길`, `Codex CLI와 비교`, `START NOW`
- 타이틀 강조: **딱 한 단어만** (예: "끝났다", "USB-C", "다를까")
- 타이틀 폰트: 80~96px, 두 줄, accent 단어에 색

### 3. 콘텐츠 블록이 비주얼

| 콘텐츠 종류 | 패턴 |
|---|---|
| 비교 (2개) | **전/후 카드 + 화살표** (MCP 04 스타일) |
| 비교 (3개+) | **표** (axis | A | B) 또는 행별 색 배지 + 장점/한계 셀 |
| 정리 (3줄) | **번호 카드 01/02/03 + 헤딩 + 서브** |
| 정의 | **본문 단락 3-4줄 + 하단 callout** |
| 명령/단계 | **번호 + 코드 블록** 짝지어 |

### 4. 색 = 정보 (시맨틱)

| 색 | 의미 | 사용 |
|---|---|---|
| 라임 (`#c4ff3d`) | 메인·강조 | accent 단어, 라벨, 핵심 callout |
| 녹 (`#58e07a`) | 긍정·장점 ✓ | 헤더 라벨 "장점", ✓ 마크 |
| 빨 (`#ff6b6b`) | 부정·한계 ✗ | 헤더 라벨 "한계", ✗ 마크 |
| 파 (`#6fb8ff`) | 대안·대비 | 비교 대상, 대체 경로 callout |

**중요:** 색은 정보를 코딩한다. 단순히 시각 다양성 위해 색을 쓰면 시맨틱 혼선.
배지·옵션 라벨에는 중립색만 쓰고, ✓/✗ 마크에 상태색 적용.

### 5. 여백 (호흡)

- 콘텐츠는 캔버스의 **60-70%** 만 채움
- 하단 30-40% 의도적으로 비움
- 콜아웃 박스가 콘텐츠와 푸터 사이 brigde 역할

### 6. 콜아웃 박스 (페이지마다 1-2개)

```
┌──────────────────────────────────────┐
│ Claude는 길게 생각, Codex는 빨리 답  │  ← 한 줄 takeaway
└──────────────────────────────────────┘
```

- 라임 보더 + 어두운 배경
- 가운데 정렬, 한 줄 메시지
- 강조 단어 1-2개 accent

### 7. CTA 페이지 구성

```
[브랜드 스트립]
[작은 라벨 가운데: START NOW]
[큰 타이틀 가운데, 한 단어 accent]
[서브 카피 2줄 가운데]
[브랜드 링/마스코트 (선택)]
[알약 CTA 버튼]
[하단 URL/프로모 (선택)]
```

## 콘텐츠 전개 패턴 (8장 기준)

### 표준 흐름
```
01 cover         후킹 (한 단어 accent + 짧은 sub)
02 정의/맥락     "이게 뭐냐" 한 줄 + 본문 3줄 + callout 사실
03 비교/맥락     다른 옵션과 차이 (표)
04 특징/구조     3-4가지 핵심 (그리드 카드)
05 방법/선택     장단점 비교 (pros/cons 표)
06 액션 1       구체 명령 / 코드 블록
07 액션 2       단계별 (번호 카드)
08 CTA          행동 유도 + 다음 단계
```

### 콘텐츠 깊이 룰

각 페이지 작성 전 자문:
- **"이 페이지 보고 독자가 어떤 새 깨달음을 얻나?"**
- 답이 평범한 사실이면 → 다시 생각
- 답이 통찰(반전·연결·"아 그래서 그런 거구나")이면 → 그걸 카피의 중심으로

### 카피 품질 기준

- **메타 내레이션 X**: "핵심 차이는 ~다", "이제 알게 된 것은" 같은 설명조 금지
- **평가어 X**: 강력한·완벽한·혁신적인·필수·압도적·최고의·단연
- **한 문장 2줄 이내**: 폰에서 길면 안 읽힘
- **입말 톤**: "쓰는 거다", "끝난다" — 격식체 X
- **한자어 → 한글**: 자동 호출 → 자동 실행, 처리한다 → 한다
- **영어 명사 표기 통일**: 시리즈 안에서 같은 표기 (Claude Code, Codex CLI, Opus 4.7)

### 사실 정확도

- 모델명·버전·수치는 단정형 위험 (변동 빠름) → "최대 1M 컨텍스트" 같이 유연
- 라이선스·상품명: 공식 표기 그대로 (Apache·OAuth·Pro/Max/Team/Enterprise)
- 출처 없는 평가는 회피 ("프로덕션급" → 구체 사실로 대체)

## DEEPDIVE 시리즈에서 가져올 것 (선택적)

Claude 시리즈는 짐코딩형이지만, 표지에서는 DEEPDIVE 스타일도 옵션:

- 인물·제품의 실 사진/스크린샷을 표지 hero로 쓸 때
- 발표·신상·핫 토픽을 다룰 때 임팩트 우선이면 채택

단 일관성 위해 **표지 외에는 짐코딩형 콘텐츠 블록** 유지.
